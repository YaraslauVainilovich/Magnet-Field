# Magnet Field Design Handoff

Статический дизайн-пакет без Figma. Основан на механике Magnet Field: положительные красные клетки, отрицательные синие, нейтральные серые, слияния по номиналу и заряду.

## Структура

```text
magnet-field-design/
  index.html
  styles.css
  design-tokens.json
  README.md
  assets/
    icon.svg
    tile-positive.svg
    tile-negative.svg
    tile-neutral.svg
    charge-plus.svg
    charge-minus.svg
    charge-neutral.svg
    icon-menu.svg
    icon-undo.svg
    icon-hint.svg
    icon-reset.svg
    field-lines.svg
```

## Что где лежит

- `index.html` — структура дизайн-системы: меню, игровой экран, компоненты, состояния, палитра.
- `styles.css` — визуальная система: цвета, размеры, отступы, скругления, тени, плитки, кнопки, карточки, состояния.
- `design-tokens.json` — машинно-читаемые design tokens для разработчика.
- `assets/` — отдельные SVG-ассеты: иконка приложения, базовые плитки, иконки зарядов, UI-иконки.

## Рекомендуемый рабочий процесс

1. Открыть `index.html` в браузере.
2. Проверить читаемость меню и игрового экрана на мобильном размере.
3. Все цвета и размеры менять сначала в `:root` внутри `styles.css`.
4. При переносе в движок игры использовать `design-tokens.json` как источник значений.
5. SVG из `assets/` можно импортировать отдельно или заменить на движковые UI-элементы, сохранив цвета и радиусы.

## Важные правила

- Positive: знак `+`, красная палитра, активная теплая плитка.
- Negative: знак `−`, синяя палитра, активная холодная плитка.
- Neutral: без знака или знак `0`, серая палитра, спокойная буферная плитка.
- Декор не должен мешать чтению поля.
- Игровое поле и числа имеют приоритет над иллюстративностью.
